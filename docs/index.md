# FastScope

**One analyzer for every bundler.** A dependency graph from `stats.json`, real byte
attribution from source maps, esbuild metafiles, or a plain `dist/` folder -
merged into one graph, in a fraction of the memory.

These are the project's own documents, generated from the repository rather than
written twice. English is the normative source; the translations are listed at
the end of the table of contents.

Start with [the evidence log](en/01-evidence.md) if you want to know what is
measured and what is still a claim.
