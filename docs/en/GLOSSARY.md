# Glossary — OmniBundleScope (EN)

Canonical list per `docs/contracts/i18n-parity.md` §4. Translations:

| EN | ZH | JA | DE | notes |
|---|---|---|---|---|
| asset | 构建产物 | ビルド成果物 | Build-Artefakt | a file emitted by the build; the treemap root |
| chunk | 分块 | チャンク | Chunk | webpack's unit of async loading; has `initial` |
| module | 模块 | モジュール | Modul | one entry of the dependency graph |
| source map | Source Map | ソースマップ | Source Map | v3; the ground truth for byte attribution |
| attribution | 归因 | 帰属 | Zuordnung | mapping generated bytes back to original sources |
| fusion | 融合 | 融合 | Fusion | merging the stats graph with one or more source maps |
| ghost code | 幽灵代码 | ゴーストコード | Geist-Code | declared by the bundler, accounted for by no mapping |
| hidden code | 隐藏代码 | 隠しコード | versteckter Code | generated bytes that belong to no module |
| tree shaking | Tree Shaking | ツリーシェイキング | Tree Shaking | elimination of unused exports |
| treemap | 矩阵树图 | ツリーマップ | Treemap | squarified layout, Canvas 2D in Phase 1 |
| budget | 体积卡点 | サイズバジェット | Größen-Budget | CI gate; breach exits 1 with `OBS0040` |
| baseline | 基线 | ベースライン | Ausgangswert | the reference numbers a measurement is compared to |
| size dimension | 体积维度 | サイズ軸 | Größendimension | `stat` / `parsed` / `gzip` / `attributed` |
| phase | 阶段 | フェーズ | Phase | scan / parse / attribute / fuse / report |
| fixture | 固定样本 | フィクスチャ | Fixture | a pinned input used by tests or benchmarks |
| real fixture | 真实样本 | 実フィクスチャ | echtes Fixture | built from a real open-source project |
| synthetic fixture | 合成样本 | 合成フィクスチャ | synthetisches Fixture | generated to reach a scale real projects do not |
| parity | 等价性 | 準拠性 | Parität | agreement with a reference tool within a tolerance |
| unverified | 未验证 | 未検証 | nicht verifiziert | an allowed, expected state for an unmeasured target |
| streaming ingest | 流式摄取 | ストリーミング取り込み | Streaming-Eingabe | parsing without materialising the document |
| ceiling | 上限 | 上限 | Obergrenze | the memory/size limit that makes a tool unusable |

## Not translated

Code, identifiers, file names, CLI flags, JSON keys, diagnostic codes (`OBS0001`
…), crate names, version numbers. Translating any of these breaks the parity
checker.
